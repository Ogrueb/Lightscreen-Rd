# Lightscreen Rd 3.0.1

A bug-fix release for HDR monitors.

## Fixed

- **Browsers captured too bright on an HDR monitor.** With HDR on, Chrome could come out several times too bright, washed out with coloured fringes, in every capture mode. Lightscreen Rd now reads the screen in HDR and scales it to Windows' "SDR content brightness", so captures match what you see. HDR video or photos brighter than SDR white are clipped to white, as in any 8-bit screenshot. SDR monitors capture as before.

## Added

- **HDR capture** option on the Options tab: Automatic (default) or Off.
- `lightscreen --hdr-report` writes a diagnostic file to the desktop. If a capture looks wrong, run it straight afterwards and attach the file to your report.
- If Lightscreen Rd ever stops during an HDR capture, it turns HDR capture off at the next start and tells you; the option turns it back on.

See [CHANGELOG.md](https://github.com/Ogrueb/Lightscreen-Rd/blob/master/CHANGELOG.md) for details.

## Install or upgrade

1. Download `lightscreen-rd-3.0.1-win64.zip` below and unzip it anywhere, replacing 3.0.0 if you like.
2. Run `lightscreen.exe`. Settings, hotkeys and history carry over.

The release is not code-signed, so Windows SmartScreen may warn the first time you run it.

## Requirements

Windows 10 or later, 64-bit. Capturing a covered window in HDR needs Windows 10 version 1903 or later; older versions capture windows as before.

## Known issues

- On Windows 11, Print Screen opens the Snipping Tool unless "Use the Print screen key to open screen capture" is turned off (Settings > Accessibility > Keyboard). Turn it off, or choose another hotkey.
- With HDR on, capturing a window that another window covers can flash a yellow border for a moment on Windows 10 and on Windows 11 builds without the setting to hide it. Windows draws it; it never appears in the saved file. Uncovered windows do not flash.
- With HDR on, a window that is mostly covered, mostly off screen, on a rotated monitor or spanning two monitors is captured the old way, which can be too bright for a browser.
- PNG files always use compression quality 80.
- With "Sound cue" and the tray pop-up both on, Windows' notification sound plays with the shutter. Turn the pop-up off, or turn off Lightscreen Rd's notification sound in Windows (Settings > System > Notifications).
- The window picker shows no icon for Windows Store apps such as Settings.
- Lowering the display scaling while the app runs can leave a strip at the main window's right edge until the window is resized.
